# AI

## Panggilan dasar

```tsx
import { useAI } from "@/lib/ai";
import { AI_FIELDS_SCHEMA, type AIField } from "@/components/hitl/ReviewPanel";
import { fileToBase64 } from "@/lib/utils";

const ai = useAI<{ bidang: AIField[] }>();

await ai.run({
  system: "Peran AI.",
  prompt: "Instruksi lengkap.",
  schema: AI_FIELDS_SCHEMA,
  files: [{ name: file.name, mediaType: file.type, data: await fileToBase64(file) }],
  mockKey: "kunci-jawaban-tiruan",
});
```

| Nilai | Isi |
|---|---|
| `ai.loading` | `true` selama AI bekerja |
| `ai.error` | Pesan error, atau `null` |
| `ai.result.data` | Objek yang sesuai `schema`. `null` jika `schema` tidak ada. |
| `ai.result.text` | Jawaban sebagai teks |
| `ai.result.mode` | `"claude"` atau `"mock"` |
| `ai.reset()` | Menghapus hasil dan error |

## Parameter

| Parameter | Wajib | Isi |
|---|---|---|
| `prompt` | Ya | Instruksi untuk AI |
| `system` | Tidak | Peran dan batas AI |
| `schema` | Tidak | JSON Schema. Tanpa `schema`, jawaban berupa teks bebas. |
| `files` | Tidak | Maksimal 3 file. Maksimal 4 MB per file. PDF, PNG, JPEG, GIF, WebP. |
| `mockKey` | Tidak | Kunci di `mock/ai-responses.json` untuk mode AI MOCK |
| `maxTokens` | Tidak | Batas token jawaban. Server membatasi nilai ini sampai `AI_MAX_TOKENS`. |

## Skema siap pakai

`AI_FIELDS_SCHEMA` menghasilkan bentuk ini:

```json
{ "bidang": [ { "nama": "...", "nilai": "...", "kutipan_sumber": "...", "yakin": "tinggi" } ] }
```

- `kutipan_sumber` mengikat setiap nilai ke teks asli. Manusia bisa memeriksa nilai tanpa membaca seluruh dokumen.
- `yakin` berisi `"tinggi"`, `"sedang"`, atau `"rendah"`. `ReviewPanel` menampilkan nilai ini sebagai badge.

`ReviewPanel` menerima `data.bidang` langsung. Pakai skema ini kecuali kamu punya alasan kuat.

## Skema sendiri

Aturan dari Claude API untuk output terstruktur:

1. Setiap objek wajib punya `required` yang memuat semua properti.
2. Setiap objek wajib punya `additionalProperties: false`.
3. Pakai `enum` untuk pilihan tetap.

```ts
const schema = {
  type: "object",
  properties: {
    judul: { type: "string" },
    poin: { type: "array", items: { type: "string" } },
  },
  required: ["judul", "poin"],
  additionalProperties: false,
};
```

Jika kamu memakai skema sendiri, kamu harus mengubah hasil itu menjadi daftar `AIField` sebelum memasukkan hasil ke `ReviewPanel`.

## Menulis prompt

1. Sebut daftar kolom dengan nama persis. `ReviewPanel` menampilkan nama itu apa adanya.
2. Tulis tindakan untuk informasi yang tidak ada: "Tulis string kosong jika dokumen tidak memuat informasi itu."
3. Larang tebakan di `system`: "Kamu hanya menyalin informasi yang tertulis. Kamu tidak menebak."
4. Jelaskan arti setiap nilai `yakin`.
5. Tulis prompt dalam Bahasa Indonesia jika keluaran harus berbahasa Indonesia.

Simpan `SYSTEM` dan `PROMPT` sebagai konstanta di bagian atas file halaman. Jurnalis di tim bisa membaca dan mengoreksi prompt itu.

## Jawaban tiruan

- File: `mock/ai-responses.json`.
- Kunci = nilai `mockKey`. Jika kunci tidak ada, sistem memakai kunci `default`.
- Jawaban tiruan tidak membaca file atau prompt. Jawaban selalu sama. Halaman contoh memberi tahu pengguna tentang hal ini.

Pakai AI MOCK saat kamu membangun UI. Pindah ke AI CLAUDE setelah UI selesai. Cara ini menghemat token dan waktu tunggu.

## Audio

Claude API membaca teks, gambar, dan PDF. Claude API tidak membaca audio.

Untuk ide tentang audio, siapkan transkrip dengan cap waktu di `mock/transcript.json`. AI bekerja pada teks transkrip itu. Contoh ada di `src/pages/Transcript.tsx`.

## Pengaturan server

Env var di Netlify atau di file `.env`:

| Env var | Default | Isi |
|---|---|---|
| `ANTHROPIC_API_KEY` | kosong | Kosong = AI MOCK |
| `DEMO_ACCESS_CODE` | kosong | Wajib jika API key terisi |
| `AI_MODEL` | `claude-sonnet-5-5` | Model Claude |
| `AI_EFFORT` | `low` | `low`, `medium`, atau `high`. Nilai lebih tinggi = jawaban lebih teliti dan lebih lambat. |
| `AI_MAX_TOKENS` | `8000` | Batas token jawaban |

## Biaya dan keamanan

- API key hanya ada di `netlify/functions/ai.ts`. Jangan beri awalan `VITE_` pada key itu.
- Semua orang yang tahu kode akses demo bisa memakai token kamu. Ganti kode itu untuk setiap acara.
- Pasang batas belanja di Anthropic Console.
- Hapus `ANTHROPIC_API_KEY` dari Netlify setelah acara.
- Kirim hanya data dummy atau data publik ke AI.
